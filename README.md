# AI Chimera — 幻兽卡片生成器

基于 Google Gemini AI 生成方形幻兽卡片。

## 功能

- 输入描述，AI 生成独特的幻兽卡片
- 方形卡片格式
- API Key 仅存储在本地浏览器，不会上传服务器

## 快速开始

**前置要求：** Node.js

```bash
# 安装依赖
npm install

# 配置 API Key
# 在 .env.local 中设置 GEMINI_API_KEY=你的Gemini API密钥

# 启动开发服务器
npm run dev
```

访问 [http://localhost:5173](http://localhost:5173)。
